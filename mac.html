Press Tab to switch to the letter you meant

Amharic has letters that sound the same, like ተ and ጠ. Type the sound, then press Tab while the letter is underlined to move to the next one. Shift + Tab goes back.

type te ተ press Tab ጠ press Tab ተ

Tab changes the last letter you typed. It works on c too: you get ክ, and Tab gives ች, so you do not have to type ch.

tተTab →ጠ
sሰTab →ሠ
hሀTab →ሐ ኀ
cክTab →ች ጭ
chቸTab →ጨ
tsጸTab →ፀ
pፐTab →ጰ
aአTab →ዐ

Everything you need to write Amharic on a Mac

⌨️

Phonetic typing

Use the English letters you already know. No new layout to learn.

🎛️

Fidel palette

Click or press 1–7 to change a letter's vowel form. The key to type is labelled under each one.

💡

Suggestions

Built-in dictionary suggestions. What you typed stays the default, so you stay in control.

፲

Numbers and punctuation

Option + number for ፩–፱, and ። ፣ ፤ ፥ ፧ by shortcut or from a picker.

🔒

Private and offline

Never connects to the internet. Password fields are left alone.

🌍

Quick English

Control + Option + Space types English without leaving the keyboard.

Set up in about two minutes

The app guides you too. Full details are in the install guide.

Download and install

Open the disk image, drag Ethio Amharic for Mac to Applications, open it and press Install.

Add it in System Settings

Keyboard → Input Sources → Edit → +, choose Amharic, then Ethio Amharic Keyboard.

Pick it in the menu bar and type

Choose the keyboard from the input menu and type selam. If an app still types English, restart it.
